# Cinema Booking System

This project is a web-based cinema booking system with a relational database design.

## Features
- Movie browsing
- Seat selection
- Payment page
- Login system (frontend demo)

## Technologies
- SQL (Relational Database Design)
- HTML, CSS, JavaScript

## Database Design
Includes tables for:
- Movies
- Actors
- Directors
- Relationships (ACTS_IN, DIRECTS)
